# Phase 12.7 Spec — pi-agent-core 上移 backend agent runtime

> 状态：Design 已对齐（2026-05-15），待用户审阅 → 进入 writing-plans。
> 关联 roadmap：[`docs/requirements/roadmap.md`](../../requirements/roadmap.md) Phase 12.7 — pi 系列第三步
> 前置：Phase 12 ✅ + Phase 12.5 ✅（pi-ai LLM 层已就位）+ UX hotfixes ✅
> 编号：pi 系列连续子号（12 自研 → 12.5 pi-ai → **12.7 pi-agent-core**）；跳过 12.6（保留给未来 OAuth providers）

## 1. 目标

把 chat agent execution loop **从 frontend `useAIChat.ts` 搬到 backend**，用 `@earendil-works/pi-agent-core@0.74.0`（OpenClaw 同款 pin）。frontend 从 1011 行的「LLM SSE 消费 + tool execute 循环 + history 管理」瘦身到 ~300 行的「canonical event SSE consumer + UI 状态」。backend 拿到 pi-agent-core 的 parallel tool / sessionId caching / beforeToolCall hooks / thinkingLevel 6 档 / terminate flag 等开箱即用能力。

**为什么 backend**（关键 framing fix）：Phase 12.5 spec 当时把 pi-agent-core 写成「frontend 上移 useAIChat」是错的——pi-agent-core 设计就是 backend/CLI 用例（`streamFn for proxy backends` / `getApiKey` callback / `getEnvKeys()` 等 Node-only API），OpenClaw 也是 backend 跑 agent。本 Phase 12.7 修正这条 framing：agent runtime 在 backend，frontend 是 view-only consumer。

## 2. 不做什么

- ❌ **transformContext compaction**：当前 chat 极少超 64K context，没痛点；pi-agent-core 提供 hook，dogfood 实测需要时再加
- ❌ **steering UI（中途插话）**：frontend 输入框 mid-stream queue + 显示需独立 UI 设计，单独 Phase 做
- ❌ **cross-provider handoff UI**：pi-agent-core context 已天然支持「换 model 继续」，但 frontend「切换并继续」按钮 + 显示哪轮用了哪个 model 需独立 UI 设计
- ❌ **Custom AgentMessage 自定义 type**：现有 ChatBubble 类型（含 ai-thinking / ai-usage）工作良好，迁到 AgentMessage 自定义 type 纯重构无新价值
- ❌ **OAuth providers**（Codex / Copilot / Vertex）：留 Phase 12.6 候选独立做
- ❌ **MCP catalog 扩展**：Phase 13 主体；Phase 12.7 不动 MCP 内容只动 agent 层
- ❌ **第三次重写 useAIChat 进 pi-agent-core 客户端**：pi-agent-core 跑 backend，frontend 仅消费 SSE，**不**在 browser 里跑 Agent 实例

## 4. 架构变更

### Before（Phase 12.5 落地状态）

```
Browser useAIChat.ts (1011 行):
  loop:
    canonical request →
    POST /api/llm/chat/completions (canonical SSE)
    consume events → 累积 tool_calls
    decode finish event → build assistant msg
    POST /api/decks/:id/chats (assistant msg)
    for each tool_call:
      POST /api/tools/execute → result
      POST /api/decks/:id/chats (tool msg)
    if no tool_call: break

Backend:
  /api/llm/chat/completions → pi-ai-adapter → pi-ai.stream() → canonical SSE
  /api/tools/execute → tool registry → result
  /api/decks/:id/chats → deck_chats DB write
```

### After（Phase 12.7）

```
Browser useAIChat.ts (~300 行):
  POST /api/chat/turn { deckId, message }
  for await event of decodeSSEStream(response.body):
    switch (event.type):
      case 'text.delta': streamingContent += event.text
      case 'thinking.delta': thinkingContent += event.text
      case 'tool_execution.start' / .delta / .end: 更新 tool UI 状态
      case 'turn.end': 收尾 + GET /api/decks/:id/chats refresh
      case 'error': UI 错误展示
  // 无 loop / 无 tool execute / 无 chats POST

Backend /api/chat/turn:
  agent = createAgent(userId, deckId)  // 见 §5
  for await event of agent.prompt(message):
    SSE encode canonical event → frontend
  // agent.subscribe('agent_end') hook 已写 deck_chats
```

## 5. createAgent factory 设计

```ts
// packages/agent/src/llm/agent/index.ts
import { Agent } from '@earendil-works/pi-agent-core'
import { stream as piAiStream } from '@earendil-works/pi-ai'
import { resolveModel } from '../adapters/pi-ai-adapter.js'
import { buildToolsForUser } from './tool-bridge.js'
import { persistTurnToDeckChats } from './persistence.js'
import { translateAgentEvent } from './translate-events.js'
import { getActiveProviderConfig } from '../settings.js'
import { logServerEvent } from '../../logger/server-log.js'

export async function createAgent(opts: {
  userId: number
  deckId: number
  encryptedSettings: string
  signal: AbortSignal
}) {
  const cfg = getActiveProviderConfig(opts.encryptedSettings)
  if (!cfg) throw new Error('LLM 未配置')

  const model = resolveModel(cfg.provider, cfg.model, cfg.baseUrl)
  const tools = await buildToolsForUser(opts.userId)
  const systemPrompt = buildSystemPromptForDeck(opts.deckId)  // 复用现有 prompts/ 逻辑
  const existingMessages = await loadDeckChatMessages(opts.deckId)  // 从 deck_chats 加载

  const advanced = parseAdvanced(opts.encryptedSettings)
  const thinkingLevel = advanced?.[cfg.provider]?.thinkingLevel ?? 'off'

  const agent = new Agent({
    initialState: {
      systemPrompt,
      model,
      thinkingLevel,
      tools,
      messages: existingMessages,
    },

    streamFn: piAiStream,
    sessionId: `lumideck:user-${opts.userId}:deck-${opts.deckId}`,
    toolExecution: 'parallel',

    beforeToolCall: async ({ toolCall, args }) => {
      logServerEvent({
        category: 'agent',
        event: 'tool-call',
        userId: opts.userId,
        deckId: opts.deckId,
        toolName: toolCall.name,
        argKeys: Object.keys(args ?? {}),  // 不落实际 args（可能含敏感数据）
      })
      // 不 block,只 audit
      return undefined
    },

    afterToolCall: async ({ toolCall, result, isError }) => {
      logServerEvent({
        category: 'agent',
        event: 'tool-result',
        userId: opts.userId,
        deckId: opts.deckId,
        toolName: toolCall.name,
        isError,
      })
      // 不改 result;terminate 由工具自身 return（如 generate_slide_image 工具）
      return undefined
    },
  })

  // agent_end 写库
  agent.subscribe(async (event) => {
    if (event.type === 'agent_end') {
      await persistTurnToDeckChats(opts.deckId, event.messages)
    }
  })

  return agent
}
```

### tool-bridge.ts 设计

```ts
// packages/agent/src/llm/agent/tool-bridge.ts
import { Type } from '@earendil-works/pi-ai'  // TypeBox re-export
import { listToolsForUser, executeTool } from '../../tools/registry.js'
import type { AgentTool } from '@earendil-works/pi-agent-core'

/**
 * 把 user-scoped tool registry 当前所有 tools（built-in + MCP）wrap 成 AgentTool[]。
 * AgentTool.execute 内部调我们现有的 executeTool(name, args) 走老链路。
 * 每 turn 调一次,成本忽略（≤ 30 个 tool）。
 */
export async function buildToolsForUser(userId: number): Promise<AgentTool[]> {
  const tools = await listToolsForUser(userId)  // {name, description, inputSchema}[]
  return tools.map((t) => ({
    name: t.name,
    description: t.description,
    // pi-agent-core 接 TypeBox schema;我们 inputSchema 是 raw JSON Schema,直接转换或 cast
    parameters: jsonSchemaToTypeBox(t.inputSchema),
    execute: async (args, ctx) => {
      const result = await executeTool({ userId, toolName: t.name, args, signal: ctx.signal })
      return {
        // pi-agent-core 期望 content: ContentBlock[]
        content: result.contentBlocks ?? [{ type: 'text', text: JSON.stringify(result) }],
        isError: result.isError ?? false,
        terminate: result.terminate ?? false,  // 工具 opt-in
      }
    },
  }))
}

function jsonSchemaToTypeBox(schema: Record<string, unknown>): unknown {
  // 简化:pi-agent-core/pi-ai 运行时接 raw JSON Schema(虽然类型签名说 TSchema)
  // 直接 cast 通过(Phase 12.5 Task B 已 verified)
  return schema
}
```

### translate-events.ts 设计

pi-agent-core 发的 11 类 event → 我们 canonical event 集合（含 5 新加）映射：

| pi-agent-core event | canonical event |
|---|---|
| `agent_start` | `turn.start { turnId }` |
| `turn_start` | （drop——一个 user message 一个 canonical turn，agent 内部多 turn 不显式 surface）|
| `message_start` (role=assistant) | （drop——下游 text/thinking/toolcall delta 自包含）|
| `message_update.assistantMessageEvent.type=text_delta` | `text.delta { text }` |
| `message_update.assistantMessageEvent.type=thinking_delta` | `thinking.delta { text }` |
| `message_update.assistantMessageEvent.type=toolcall_start` | `tool_call.start { id, name }` |
| `message_update.assistantMessageEvent.type=toolcall_delta` | `tool_call.delta { id, argsChunk }` |
| `message_update.assistantMessageEvent.type=toolcall_end` | `tool_call.end { id }` |
| `tool_execution_start` | `tool_execution.start { toolCallId, toolName }` |
| `tool_execution_update` | `tool_execution.delta { toolCallId, partial }` |
| `tool_execution_end` | `tool_execution.end { toolCallId, isError, summary }` |
| `turn_end` | （drop——agent 内部多 turn）|
| `agent_end` | `turn.end { messages, usage, cost? }` + 关闭 SSE |
| `error` | `error { code, message }` |

`done` event from pi-ai stream（被 pi-agent-core 内部消费）→ pi-agent-core emit `message_end` → 我们 drop（用 turn.end 替代）。`cache.hit` event 从 `agent_end.messages.at(-1).usage.cacheRead > 0` 提取并 emit 一次（在 turn.end 之前）。

### canonical event union 扩展

```ts
// packages/shared/src/llm-canonical.ts
export type CanonicalEvent =
  | { type: 'turn.start'; turnId: string }                                     // 新
  | { type: 'turn.end'; usage: TokenUsage; reason: FinishReason }              // 新（替代旧 finish）
  | { type: 'text.delta'; text: string }
  | { type: 'tool_call.start'; id: string; name: string }
  | { type: 'tool_call.delta'; id: string; argsChunk: string }
  | { type: 'tool_call.end'; id: string }
  | { type: 'tool_execution.start'; toolCallId: string; toolName: string }     // 新
  | { type: 'tool_execution.delta'; toolCallId: string; partial: unknown }     // 新
  | { type: 'tool_execution.end'; toolCallId: string; isError: boolean }       // 新
  | { type: 'thinking.delta'; text: string }
  | { type: 'cache.hit'; cachedTokens: number; costTokens: number }
  | { type: 'finish'; reason: FinishReason; usage: TokenUsage }                // 保留（非 agent 单轮 call 仍用）
  | { type: 'error'; code: string; message: string }
```

`finish` event 保留是因为 `/api/llm/chat/completions` route 没废，`rewriteForTemplate` / `rewriteSinglePageToComponents` 这种**单轮无 tool** LLM call 继续用，发的就是 finish 不是 turn.end。

```ts
// packages/agent/src/llm/migrations.ts
export function migrateThinkingEnabledToLevel(legacy: LlmSettings): LlmSettings {
  if (!legacy.advanced) return legacy
  const mapped = { ...legacy.advanced }
  for (const block of ['anthropic', 'gemini', 'common'] as const) {
    const sub = mapped[block] as Record<string, unknown> | undefined
    if (sub && 'thinkingEnabled' in sub) {
      const enabled = Boolean(sub.thinkingEnabled)
      sub.thinkingLevel = enabled ? 'medium' : 'off'
      delete sub.thinkingEnabled
      mapped[block] = sub
    }
  }
  return { ...legacy, advanced: mapped }
}
```

## 7. POST /api/chat/turn route

```ts
// packages/agent/src/routes/chat.ts
import { Hono } from 'hono'
import { createAgent } from '../llm/agent/index.js'
import { eventsToSSEStream } from '../llm/canonical-sse.js'
import { translateAgentEvent } from '../llm/agent/translate-events.js'
import { acquireLlmSlot, LlmConcurrencyTimeoutError } from '../middleware/llm-semaphore.js'

const chat = new Hono<{ Variables: AuthVars }>()

chat.post('/turn', async (c) => {
  const user = c.get('user')
  if (!user) return c.json({ error: { message: 'unauthorized' } }, 401)
  if (!user.llmSettings) return c.json({ error: { message: '请先配置 LLM API Key' } }, 400)

  const body = await c.req.json() as { deckId: number; message: string; attachments?: AttachmentBlock[] }
  const deckId = Number(body.deckId)
  if (!deckId || isNaN(deckId)) return c.json({ error: { message: 'deckId 必填' } }, 400)

  // 验权:用户拥有该 deck
  const deck = await getDeckIfOwned(deckId, user.id)
  if (!deck) return c.json({ error: { message: 'deck not found' } }, 404)

  let release: () => void
  try {
    release = await acquireLlmSlot(user.id)
  } catch (e) {
    if (e instanceof LlmConcurrencyTimeoutError) return c.json({ error: { message: e.message } }, 503)
    throw e
  }

  const signal = c.req.raw.signal
  const agent = await createAgent({
    userId: user.id,
    deckId,
    encryptedSettings: user.llmSettings,
    signal,
  })

  // signal abort → agent.abort()
  signal.addEventListener('abort', () => agent.abort())

  const events = (async function* () {
    try {
      // 把 pi-agent-core 的 subscribe-based 事件流转成 async generator
      yield* runAgentAsGenerator(agent, body.message, body.attachments)
    } finally {
      release()
    }
  })()

  const sseStream = eventsToSSEStream(events)
  return new Response(sseStream, {
    status: 200,
    headers: { 'Content-Type': 'text/event-stream', 'Cache-Control': 'no-cache', 'X-Accel-Buffering': 'no' },
  })
})

export { chat }
```

`runAgentAsGenerator` 把 pi-agent-core 的 push-based subscribe 转成 pull-based async generator（用 buffer queue + promise resolve 模式）。完整实现见 plan §Task B。

## 8. deck_chats 持久化

agent 跑完整 turn（user msg + assistant msg + 0..N toolResult msg）后，`agent_end` event 携带 `messages: AgentMessage[]` 全部历史。持久化逻辑：

```ts
export async function persistTurnToDeckChats(deckId: number, messages: AgentMessage[]): Promise<void> {
  const db = getDb()
  // 取本 turn 新增的 messages（last N where N = turn length）
  // 简化:每次 agent_end 拿全 messages,跟 DB 已有的 chats 比较增量写
  const existing = await db.select().from(deckChats).where(eq(deckChats.deckId, deckId)).orderBy(deckChats.createdAt)

  for (const m of newOnes) {
    const row = canonicalToRow(agentMessageToCanonical(m))
    await db.insert(deckChats).values({ deckId, ...row })
  }

}
```

**Transaction**：一个 turn 的所有 messages 在单个 transaction 内写，全成功或全 rollback。失败时记 `logServerEvent({ category: 'agent', event: 'persist-failed' })`，不影响 SSE 已 emit 的 `turn.end` 事件（前端拿到的是 in-flight 数据，DB 失败用户下次 refresh 才发现缺历史）。

## 9. frontend useAIChat 瘦身
